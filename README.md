# transit-router

A small route planner for a made-up city metro. Given two stations it answers
two different questions:

- **Fewest stops** — what's the route with the least stations in between?
- **Fastest trip** — what's the route that gets me there in the least time?

They are not always the same route, and finding out why is the point of this
project. It's my practice ground for graphs (Advanced Data Structures).

Plain Python 3, standard library only.
